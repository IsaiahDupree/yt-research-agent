# Weekly research reports

Auto-generated by the [weekly-research](../../.github/workflows/weekly-research.yml) GitHub Action every Monday at 09:00 UTC. Each report is the full pipeline output for the configured niche (default: `algorithmic trading`).

The accompanying diff lives in [`../diffs/`](../diffs/) and shows what changed since last week's report — new outliers, dropped outliers, new ranked signals, dropped signals. The PR opened by the workflow embeds the diff as its body.

## Triggering manually

```bash
gh workflow run weekly-research --field niche="esports analytics"
```

## Filenames

`YYYY-MM-DD.md` — the date the report was generated (UTC).

## Wiring in real API keys

The workflow runs with demo fixtures by default — zero secrets, zero quota.
Drop these in as repo secrets to switch to live API calls:

- `YOUTUBE_API_KEY` — YouTube Data API v3
- `ANTHROPIC_API_KEY` *or* `OPENAI_API_KEY` — LLM brief generation
- `REDDIT_CLIENT_ID` + `REDDIT_CLIENT_SECRET` — Reddit signals

Then uncomment the matching `env:` lines in `.github/workflows/weekly-research.yml`.
